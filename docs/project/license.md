# License

Space Works is free and open source software, licensed under the **GNU Affero General Public License,
version 3 or (at your option) any later version** (AGPL-3.0-or-later). The governing text is the `LICENSE`
file in the repository. This page is a plain-language summary, not legal advice; the license text wins.

## What you can do

You may use, study, share and modify Space Works freely, for any purpose, commercial or noncommercial. There
is no fee, no seat count and no per-makerspace permission to ask for. You can run it for your own makerspace,
for your organization, or as a service for others.

## What the AGPL asks of you

The AGPL is a "network" copyleft license. In practice:

| You are... | What it means |
| --- | --- |
| **Self-hosting an unmodified release** | Nothing extra. Run it, back it up, update it. |
| **Modifying it for your own use** | If you only run it yourself and nobody else interacts with it over a network, you have no obligation to publish. |
| **Running a modified version that other people use over a network** | Everyone who interacts with it must be offered the corresponding source code of your modified version, under the same license. This is the part that sets the AGPL apart from the plain GPL. |
| **Distributing copies, modified or not** | Pass on the same license, keep the copyright and license notices, and make the source available. |
| **Hosting other makerspaces on your own install** | The same rules apply: if you modified the software, your users must be able to get your modified source. Unmodified, there is nothing extra to publish. |

A simple way to stay compliant if you modify it: publish your changes in a public fork and link to it from
your site. The repository's `NOTICE` file carries the copyright line and licensing summary.

## Contributions

There is no contributor license agreement. By submitting a pull request you offer your contribution under the
same AGPL-3.0-or-later license (inbound equals outbound). You keep the copyright in what you contribute. See
[Contributing](contributing.md).

## Not covered by the AGPL

A few things in the repository carry their own terms, listed on [Third-party software and fonts](third-party.md):
the self-hosted fonts, and the many open-source dependencies, each under its own license.

The AGPL also gives no warranty. The software is provided as is, as the license text states.
