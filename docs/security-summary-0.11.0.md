> **Superseded.** The 0.11.0 candidate was never published; its changes ship in 0.12.0. This security summary is kept as history — use the [0.12.0 security summary](security-summary-0.12.0.md).

The reviewed development-tool exception is [GHSA-g3hv-75wg-m249](https://github.com/isaacs/minimatch/security/advisories/GHSA-g3hv-75wg-m249), affecting minimatch 10.2.6. All direct callers are development lint/parser dependencies. The affected aggressive optimization path is not enabled by the checked-in configuration; instrumentation of actual configuration resolution recorded 29 normal optimization calls and no aggressive calls. The application does not accept remote glob patterns or ship these tools in its production browser image. Keep this bounded exception visible until upstream consumers adopt a fixed compatible range, or a separately tested tooling update replaces it. A forced major-version override was not applied to the frozen candidate. Reassess this exception if configuration or call paths change.

The four additional SPEC14 card/programme/import/print browser stories passed on one EEA candidate. Actual PDF jobs, output page geometry, full identifiers and all five rendered QR symbols were checked. The broader browser/role/module matrix, latest-source backend regression, final responsive visual review and hosting/old-version upgrade checks are still pending. No physical CR80 or A4 duplex printer was tested.

The native candidate image check does not establish a multi-platform image result or a full operating-system vulnerability scan. List those outcomes separately rather than extending a Python-package audit beyond its scope.
