Consumables are used up, never lent: screws, glue, sandpaper.

## Set up

1. Open an item with a counted quantity.
2. Mark it as a consumable in its details, and set a reorder point.

## Use the list

1. Open **Consumables**. Tabs show **All**, **Running low** and **Stocked**.
2. Press **Log use**, enter how many were used and an optional note.
3. When something runs low, press **Open To-Buy**. A draft may already be waiting there.

![Screenshot: the Consumables list with Running low](screenshot:im-consumables)

> **Who can do this:** anyone who sees inventory or machines can log use; Inventory Managers set items up.
