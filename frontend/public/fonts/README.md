# Font files

Brand typography (Space Works brand kit, 15 October 2026): **Gilroy** Regular 400, Medium 500, SemiBold 600
and Bold 700 for all text and headings, and **Unbounded** 500–600 for one short accent phrase per layout.

The four `Gilroy-*.woff2` files are lossless WOFF2 repackagings of the `Gilroy-*.woff` files in the
SpaceWorks-Design repository (`fonts/`), which are format conversions of the owner's installed fonts,
included at the owner's request. Glyph outlines and coverage are unchanged. The files all report weight
class 400, so the CSS assigns each face its intended weight. Their inclusion does not make Gilroy an
open-source font; use them under the applicable Gilroy license.

`Unbounded-Variable.woff2` is covered by `LICENSES/OFL-Unbounded.txt`.
