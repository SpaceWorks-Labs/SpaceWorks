Space Managers switch modules on and off themselves, and switching off always keeps the data. Two things stay with you: installing a module that carries a usage limit on a hosted plan, and deleting data for good.

## Install a limited module

Open the space's **Modules** and switch it on. A module with a usage limit says so; only you can install it.

## Purge maintenance, To-Buy or warranty data

1. Make sure the feature is switched off in the space.
2. In `/control/`, open the space and choose **Preview and purge…**.
3. Confirm your identity again, and read the preview of what will be deleted.
4. Type the feature's key to confirm, and purge.

![Screenshot: the purge preview in /control/](screenshot:sa-purge)

## Purge a whole module's data

This is done from the server by the host operator: list what a module holds, then purge it for one space, typing the space's short name back to confirm.

A purge can't be undone. Payment records are always kept, and every purge is audited in the space.

> **Who can do this:** the platform superadmin (and the host operator for whole-module purges).
