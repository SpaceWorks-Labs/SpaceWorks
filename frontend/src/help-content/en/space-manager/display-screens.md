A display screen runs your public information full-screen on a TV or kiosk browser. It shows only what a visitor who is not signed in could see.

## Pair a screen

1. Under your space's features, switch on **Display screens**.
2. On the TV's browser open `/display` on your site. It shows a short pairing code. The code is valid for 30 minutes.
3. In the console open **Settings**, then **Display screens**. Type the code and press **Pair screen**.
4. Give the screen a name, pick the **panels** and their order (**Here now**, **Events calendar**, **Machines now**, **Announcement**) and set the seconds per panel, between 5 and 120.
5. Press **Save changes**. The screen picks it up within about ten seconds.

![Screenshot: the Display screens settings with a paired screen](screenshot:sm-display-screens)

## Keep it tidy

- An announcement can be up to 280 characters.
- The list shows each screen as **Online** or **Offline**. **Unpair** stops one at once.
- A panel appears only while its area (Presence, Machines, Events) is on.
- Names appear only for people whose profile is open to the web and who did not hide themselves; everyone else is a count. **Machines now** never shows who is using a machine.
- If the network drops, the screen keeps the last data and says "Reconnecting".

> **Who can do this:** the Space Manager.
