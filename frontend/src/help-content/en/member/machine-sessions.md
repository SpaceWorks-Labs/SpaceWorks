Some machines you run yourself. A session records how long you used it, and bills the hourly rate where the space charges for machine time.

## Start and stop

1. Scan the QR on the machine. The page is **Use this machine**.
2. Check the rate, the longest session allowed and when the space closes.
3. Press **Start session**.
4. Press **Stop session** when you're done.

![Screenshot: the Use this machine page with Start session](screenshot:member-machine-session)

**My machine sessions** lists every session you've run.

## If you forget to stop

A session stops by itself at the longest allowed time (four hours unless the space sets another), when you check out, or at closing time. Those sessions are marked for staff to check the time. The rate is fixed when you start.

> **Who can do this:** members who are checked in and certified for that machine type.
