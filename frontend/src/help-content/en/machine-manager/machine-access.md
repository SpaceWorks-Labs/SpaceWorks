Members can use a machine only when you have given them access, unless the machine is **open to all members**. Certifications and trainings no longer decide this.

## Give access

1. Open **Machines**, then **Machine access** (or the **Machine access** tab on a machine type or a machine).
2. Choose a **machine** (just that one) or a **machine type** (every machine of that type).
3. Search for members and add them. You can add several at once.
4. Add an end date if the access should stop on its own, and a note if you want one. Press **Give access**.

![Screenshot: the Machine access list with the Give access form](screenshot:mm-machine-access)

From the member register you can also select many members and press **Give machine access**, and each member's own page lists their access.

## Take it away or renew it

Press **Revoke access** on a row and confirm. The record stays in the history, and the member is told. Giving access again to someone who already has it renews it with the new end date.

## Open to all members

On a machine's **Access** tab, switch on **Open to all members** and any active member may use that machine with no grant. It is off by default.

## What it covers

Starting a machine session, sending a machine job, booking a room or machine linked to a machine type, linking a machine booking to an event, and a card, PIN or NFC tap at a connected machine. A supervised session is separate: an instructor can take someone with no access onto a machine.

Members are told when access is given or removed, and a week before it ends. Every change is audited.

> **Who can do this:** the Space Manager for everything; a Machine Manager for the machine types and machines they are linked to.
