Machine use is **given by the Space Manager**. A Machine Manager can give it inside their own machines and types.

- Give or take away access under **Machines**, **Machine access**, from a machine type, a machine, a member's page, or the member register.
- A machine can be **open to all members** (off by default), so no grant is needed.
- Certifications, trainings and induction events are retired. Old records are kept as history and nothing is deleted.
- On upgrade, everyone who qualified through a certification kept access as a grant, and machines that were never gated were opened to all members.

## Give someone access

1. Open **Machines**, then **Machine access**.
2. Choose a machine or a machine type, add the members, and set an end date if you want one.
3. Press **Give access**. The member is told, and the grant shows on their page.

![Screenshot: the Machine access list with the Give access form](screenshot:sm-machine-access)

See [Machine access](help:machine-manager/machine-access) for every option.

> **Who can do this:** the Space Manager; a Machine Manager for the machine types and machines they are linked to.
